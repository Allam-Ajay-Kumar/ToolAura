1. Project Overview

Tool Aura is a full-stack AI Tools Discovery Platform built using the MERN stack (MongoDB, Express.js, React.js, Node.js). It serves as a curated directory where users can browse, search, and explore AI tools across various categories such as Writing, Coding, Image Generation, Video, and more.


The platform supports two distinct roles — Admin and Regular User — with a complete content moderation workflow. Users can submit new AI tools which go through an admin approval process before appearing in the public directory.

🌐 Live Application: https://tools-aura-04.web.app  |  ⚙️ Backend API: https://tool-aura-backend-production.up.railway.app

5. Key Features

🔍

Search & Filter

Real-time search by tool name/description + category filter with URL query params

🔐

JWT Authentication

Secure login/register with JWT tokens stored in localStorage. Auto-attached to every API request.

🛡️

Role-Based Access

Admin and User roles with protected routes. Admins get a full dashboard; users get personal pages.

📥

Tool Submission & Moderation

Users submit tools → pending status → admin approves/rejects → appears in directory.

❤️

Favourites System

Logged-in users can save any tool to their favourites list and manage it from their dashboard.

📊

Admin Dashboard

Stats overview, manage all tools (CRUD), review submissions, manage users & categories.

📄

Pagination

Server-side pagination on tool listings. 12 tools per page with page navigation.

📱

Responsive Design

Mobile-first Bootstrap 5 layout. Works on phones, tablets, and desktops.

8. API Documentation

Base URL: https://tool-aura-backend-production.up.railway.app/api

Auth Routes /api/auth

MethodEndpointAccessDescription
POST /auth/registerPublic Register new user. Body: name, email, password
POST /auth/loginPublic Login user. Returns JWT token. Body: email, password
GET /auth/me🔒 Auth Get current logged-in user profile

Tool Routes /api/tools

MethodEndpointAccessDescription
GET /toolsPublic Get approved tools. Query: search, category, page, limit
GET /tools/:idPublic Get single approved tool by MongoDB ID
POST /tools/submit🔒 Auth Submit new tool for review. Body: name, description, category, websiteUrl

User Routes /api/users

MethodEndpointAccessDescription
GET /users/my-submissions🔒 Auth Get tools submitted by the logged-in user
GET /users/favourites🔒 Auth Get user's favourite tools list
POST /users/favourites/:id🔒 Auth Add a tool to favourites
DELETE /users/favourites/:id🔒 Auth Remove a tool from favourites

Admin Routes /api/admin

MethodEndpointAccessDescription
GET /admin/dashboard🛡️ Admin Dashboard stats: total tools, users, pending count
GET /admin/submissions🛡️ Admin Get all pending tool submissions
PATCH /admin/submissions/:id/status🛡️ Admin Approve or reject a submitted tool
GET /admin/tools🛡️ Admin Get all tools (all statuses)
POST /admin/tools🛡️ Admin Add a tool directly (auto-approved)
PATCH /admin/tools/:id🛡️ Admin Update tool details
DELETE /admin/tools/:id🛡️ Admin Delete a tool permanently
GET /admin/users🛡️ Admin Get all registered users
PATCH /admin/users/:id/toggle🛡️ Admin Activate / deactivate a user account

Category Routes /api/categories

MethodEndpointAccessDescription
GET/categoriesPublicGet all categories
POST/categories🛡️ AdminCreate new category
PATCH/categories/:id🛡️ AdminUpdate category
DELETE/categories/:id🛡️ AdminDelete category

12. Local Setup & Installation Guide

Prerequisites

🟩 Node.js v18+
🍃 MongoDB (local or Atlas)
📦 npm

Step 1 — Clone / Download the Project

cd "c:\Users\NANDINI\OneDrive\Desktop\ai tools"

Step 2 — Install Backend Dependencies

cd backend
npm install

Step 3 — Configure Backend Environment

# backend/.env
PORT=5000
NODE_ENV=development
MONGO_URI=mongodb://localhost:27017/ai_tools_directory
JWT_SECRET=your_secret_key
JWT_EXPIRE=30d
FRONTEND_URL=http://localhost:5173

Step 4 — Seed the Database

node seeder.js
# Output: ✅ Database seeded successfully!

Step 5 — Start the Backend

npm run dev
# Server running on http://localhost:5000

Step 6 — Install Frontend Dependencies

cd ../frontend
npm install

Step 7 — Start the Frontend

npm run dev
# App running on http://localhost:5173
